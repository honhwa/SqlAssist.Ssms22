## F12 腳本開頭加 USE [db] + GO

需求：跳到定義產生的腳本開頭要有 `USE [資料庫]` 與 `GO`。

做法（排版仍只有 `TSqlScriptRenderer` 一份）：
- `SqlScriptOptions.IncludeUseDatabase`（預設 false）——新的批次選項，放在「批次與樣板」組。
- `TSqlScriptRenderer.Render` 在 `AppendHeaderComment` 之後叫 `AppendUseDatabase`：
  資料庫名取 `SqlScriptContext.DatabaseName`，走同一份 `Identifier` 加方括號；
  沒有名稱就整段不寫（`USE []` 是語法錯誤，猜一個會指到別的資料庫）。
  這個 Statement 用 `requiresBatch: true`，所以批次分隔關掉時仍然有自己的 `GO`
  （USE 執行時才生效，同批次後面的敘述編譯時看不到新資料庫）。`RequiresBatch` 的
  註解由「CREATE TRIGGER 這一族」擴成兩種情形。
- `SqlScriptPreferences.CreateForExecution` 蓋第四項 `IncludeUseDatabase = true`；
  預覽那一份（`Create`）不動，所以 `SqlSearchDefinitionLoader` 的唯讀預覽沒有 USE。
- `SqlObjectScript.SkipLeadingSetBatches` → `SkipLeadingSetupBatches`，多放行 `USE `
  行；否則 F12 游標會停在整份腳本最前面。

Check-Docs（script-generation.md 一度 4551 超線，回頭刪冗餘降到 4500 以下）、
Check-TextFiles、Check-DocLinks 全通過。實跑輸出確認第一行就是 `USE [Library]` + `GO`，
游標落在 `CREATE TABLE [dbo].[Lib_Reader]` 之後。
