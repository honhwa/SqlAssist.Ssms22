## 優化：INSERT 欄位與值游標互相黃底標記

- 需求：INSERT 有欄位清單時，游標停在欄位上→對應值黃底；停在值上→對應欄位黃底。
  依 `CLAUDE.md` 工作契約先用 AskUserQuestion 對齊三項決策：
  只標另一端（不是兩端都標）、多組 VALUES 只認第一組、新增獨立開關（不依附展開開關）。
- 設計岔路：支架已有 `BlockEndpointTagger`「游標落一端、配對另一端即時上色」可仿，
  但它同時標兩端且共用括號配色；本功能只標另一端，故建立獨立的 view 級狀態與
  `ClassificationTag` tagger，黃底用與搜尋命中同族的螢光筆黃 `#FFEE58`／深字 `#1A1A1A`。
- Core 純邏輯：新增 `SqlInsertColumnValueMatcher`／`SqlInsertColumnValuePair`
  （`Core/Statements`）。用 `SqlTokenizer.Tokenize` + `SqlTokenNavigator.FindClosingParenthesis`
  ／`FindListItemEnd` 從既有 INSERT 文字反查第一組 VALUES 的成對 span；
  支援 `TOP (n)`、`INTO`、限定名稱、方括號欄位、`OUTPUT` 子句、`dbo.f(1, 2)` 與 `N'a,b'`
  內的逗號；註解中的假 INSERT 不認；`FindCounterpart(position)` 回另一端 span。
- 設定鏈四處＋兩語系：註冊檔 `sqlAssist.insertion.highlightInsertColumnValue`（預設 true、
  order 370、無 enableWhen）→ `SqlAssistMonikers.HighlightInsertColumnValue` →
  `SqlAssistSettingsReader` → `SqlAssistSettings.HighlightInsertColumnValue`（與
  `ExpandInsertStatement` 分開，手寫 INSERT 也生效）；`SettingsPageText.{zh-Hant,en}.resjson`
  加標題與說明。
- Ssms22 接線：`Blocks/InsertPairViewState.cs`（view 級 singleton，同時監聽
  `Caret.PositionChanged` 與 `TextBuffer.Changed`，排到 `TextViewDispatch.AfterCurrentCommand`，
  避免游標跟著編輯位移時漏更新）＋`Blocks/InsertPairTagger.cs`（`IViewTaggerProvider`，
  仿 `BlockEndpointTagger` 的 `GetTags` 就地平移、`TagsChanged` 只失效新舊 span，
  高對比改走 `SystemColors.HighlightColor`）＋`UI/InsertPairFormat.cs`（新分類型別
  `SqlAssist.InsertColumnValue`，DisplayName 進 `ChromeText.*.resjson`）。
